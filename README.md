# 1min PWA v0.8

公開側には個人名・学習履歴を一切含めない設計です。

## 仕様
- アプリ名: 1min
- 初回起動時に利用者が表示名を入力
- 表示名は利用端末内の localStorage のみに保存
- 国語・数学・英語の記録
- 1教科以上でその日の継続扱い
- 月間カレンダー表示（🌱 / 🌿 / 🌳）
- 左右スワイプ、または ‹ › ボタンで過去・未来の月へ移動
- JSONバックアップ / 復元
- CSV書き出し
- バックアップファイル名にも個人名を入れない
- PWA / オフライン対応

## プライバシー
公開ファイルには個人名の例示も含めていません。
実際の表示名と学習記録は、利用する端末内だけに保存されます。
バックアップは非公開の保存先を利用してください。

- 月間カレンダーは7列×最大6週で固定表示
- 今日・過去の日付をタップして記録編集
- 未来日は表示のみ

## v0.8の追加仕様
- 累積チリツモ日数：国語・数学・英語のいずれかに記録がある日を1日として集計。同日に3教科取り組んでも1日。
- 休んだ日には減らない。過去日編集・取り消し・バックアップ復元時は記録から再計算する。
- 次の10日区切りまでの残り日数を表示。10日達成時には次の20日まであと10日となる。
- 10日ごとにスペシャルカードを開放し、達成済みカードは何度でも見返せる。
- 第1章：芽／葉／木／花／鳥／木漏れ日／巣／風／成長／最初の木。
- 100日以降も100日単位の章で継続。各章で同じ10段階を巡り、200日で2本目、300日で3本目の木が育つ。累積日数の上限は設けない。
- 記録修正で必要日数を下回ったカードは未達成に戻る。カードの履歴は別保存しない。
- 不正な日付と未来日の記録は累積日数から除外する（元の保存記録は変更しない）。
