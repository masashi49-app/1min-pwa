# 1min PWA v0.1

公開側には個人名・学習履歴を一切含めない設計です。

## 仕様
- アプリ名: 1min
- 初回起動時に表示名を入力
- 表示例: 「柏さん、1分だってチリツモ。」
- 表示名はiPhone内の localStorage のみに保存
- 国語・数学・英語の記録
- 1教科以上でその日の継続扱い
- 最近7日の表示
- JSONバックアップ / 復元
- CSV書き出し
- バックアップファイル名にも個人名を入れない
- PWA / オフライン対応

## GitHub Pagesに置くもの
- index.html
- manifest.json
- service-worker.js
- icon-192.png
- icon-512.png

## 重要
GitHub側の公開ファイルには「柏」という名前は含まれていません。
実際の表示名と学習記録は、利用するiPhone内だけに保存されます。
バックアップは pCloud の非公開フォルダへ保存してください。
